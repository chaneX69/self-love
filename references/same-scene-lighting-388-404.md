## 对照方法与证据边界

同场景系列比跨场景拼色更适合分辨“什么不变、什么随照明改变”。先认同一块立面、同一根灯杆、同一区衣料，再比较其亮暗、色相、亮形、细节可见度和前后关系。

- 城市场景的中央交叉支撑高楼、弧形横杆、路灯及右侧较低老楼是稳定结构锚点；屋顶系列比较白兜帽、黑衣膝部、楼顶设备和背景楼群。人物来源与镜头发生世界分开，本批沿用迈尔斯本土场景标签，不扩展到客串人物的原生世界。
- 不是严格配准的单变量实验：广告换画、人物移动、部分取景与姿势也在变化，404尤其明显。排除这些内容变化后作定性比较，不能把所有像素差异归因于时间或材质。
- 下表是可见光照状态，不赋予准确钟点、太阳方位角或天气成因。薄雾／浓雾是对可见空气遮蔽效果的描述，不据此断言下雨。混合光中的单个高光不能可靠反推出唯一灯源。
- 颜色名称为目测描述，不新增精确HEX、面积、粗糙度、折射率或反射系数。截图压缩、显示与印刷纹理都会影响细节判断。

## 材质不变，响应因表面而异

| 材料／载体 | 保持的身份特征 | 随光变化的表现 | 避免的误读 |
| --- | --- | --- | --- |
| 黑色织物 | 深色主体、衣褶／张力、局部细密织纹 | 日光下局部细碎暖亮纹，夜里少量蓝／粉亮区；暗处可减少细纹可见度 | 纹理可见不等于金属、碳纤维或乳胶；不能全身均匀提亮，也不能用一条白描边代替材质 |
| 白色兜帽与衣袖 | 浅色材料、大面转折、边缘与厚度 | 暖光下偏乳白，夜光下蓝／粉分区明显；不同面不必同色 | 不死守纯白，也不把受光粉色当成粉色布；一般彩光不是广告图案的清晰映像 |
| 玻璃幕墙 | 窗格、面朝向、连续平面与反射边界 | 可呈成片环境色、局部强亮面；夜里楼体与窗内光形成另一层级 | 391金色强亮不证明每扇窗都镜面反射同一完整景物；不能凭空造映像 |
| 砖石／不透明墙 | 厚度、檐口、窗洞、层间节奏 | 宽面冷暖、投影和深窗洞；夜里压暗仍保留大体块 | 不变成与广告屏一样的发光板，也不随意加镜像广告画 |
| 灯杆／喷漆金属 | 稳定截面、弧线、遮挡和接点 | 日间浅亮，逆光和夜里可近黑；只在有依据处出现窄亮带 | 金属不必永远闪白，黑剪影不是材质丢失；不要整根镀铬 |
| 屋面／通风设备 | 地面粗粒与面透视；设备框边、百叶缝隙和硬边 | 屋面宽缓受光，设备有分组明暗与窄边；接触处留暗 | 粗粒不能当大网点，百叶不能当排线，干屋顶不能为夜景新增水光 |
| 广告屏／灯管 | 屏框、显示平面、图案位置；灯管原有形状 | 自发光源可有局部溢光，入夜后相对环境更突出 | 广告内容不是玻璃倒影；换画不是材质改变；不能借参考增加屏幕或灯管 |

## 反光与气氛分四层处理

1. **表面高光／环境反射**：亮形受表面方向、曲率、微纹理及光源形状共同影响。玻璃亮面与黑衣细碎光泽不是同一种笔法；无清楚映像时只保留可见亮形，不补造反射源。
2. **漫反射受光与环境染色**：白衣上的宽蓝／粉面仍表现衣服体积，不投射整张广告。可判断与附近彩光相容，不能从静帧唯一确定每块颜色来自哪一盏灯。
3. **自发光与溢光**：屏幕首先是边界明确、有内容的发光面，其附近光晕另处理；表面被照亮不等于自身发光。昼夜对照证明的是相对视觉地位改变，不是测得屏幕输出一定增加。
4. **空气散射／遮蔽**：396–397远处楼体逐渐丢失对比，近杆较清楚；发光面穿过雾显得更柔。用远近层次变化组织空气，而非统一灰蒙版、全图失焦或把玻璃粗糙度加大。

图中的织纹、窗格、显示屏点阵感、屋顶碎粒、最终画面的印刷网目要分别识别。仅凭截图不能反推具体渲染层；更不能把一种点纹重复计作多种材质或用户要求的四项印刷层。

## 建筑与配色共同组织空间

建筑读取顺序是大轮廓／体块与遮挡 → 立面转折／窗组节奏 → 灯杆、招牌框等中尺度结构 → 局部微纹理。夜里或雾里可以减少远楼小窗的可见度，不能更改实际窗列位置、层数、大轮廓和透视。彩屏始终附着于原有立面与框架，不成为任意漂浮色块。

| 条件 | 主要颜色与明暗分工 | 气氛读取（审美推论） |
| --- | --- | --- |
| 晴亮日光 | 青蓝天空、暖亮立面、冷暗楼体；广告保留固有图案色 | 空间清晰、城市信息密集而通透 |
| 低角度暖光 | 集中的金色强亮、暖中间面、冷紫暗面与深色前景杆 | 温暖且有方向感、体积和纵深更戏剧化；不是全部橙黄 |
| 暮色 | 环境亮度下降，灰紫／暖灰连接，屏幕青粉相对突出，小暖灯点 | 自然光与人工光交接，保留安静中间色 |
| 霓虹夜 | 大暗楼体分隔高彩屏幕，白亮点与少量暖光分出层次 | 繁密、有能量，但深暗区域使颜色不糊成一团 |
| 雾化夜 | 远处低对比与空气色，近处杆／信号灯较清楚，屏幕柔化 | 距离被空气包裹，不等于建筑被删除或全画面柔焦 |

屋顶近景还有另一种平衡：背景屏幕高彩且信息多，人物黑衣大暗形相对安静，浅色兜帽成为读取焦点。可借这种前景／背景组织，不据此断言角色真实心理，也不强制每张人像黑衣白帽。

## 应用到照片的决策与验收

### 693–698换光续证

[638–698记录](film-sequence-638-698.md)补充两组对照。693–696近似城市环境从暖桃／珊瑚照面走向蓝暮和深蓝天空，窗组变成局部青色亮点，黑红人物仍可作为暗剪影；镜头和姿势变化不能归因于光照。697–698白枕与白T的暖白／灰响应转成低亮蓝，皮肤与黑发保持各自明暗角色，灯边网点亮场消失；耳机、手势及闭眼状态同时变化，不能当成严格的同物体同机位曝光实验。

全帧采样L50：693约45.2、694约25.0；697约31.1、698约9.8。这是截图分析的相对明度统计，非测得照度、灯功率或相机曝光。使用时先保留原照材料和光源关系，不给照片自动加耳机、灯具、蓝布或夜景。

- 先记录原照固定项：建筑轮廓、立面模块、光向、人物姿态、主要材料、反光载体和真实光源；再选一组相近光照状态作为主参考。399–403可作黑／白布料的不同照明对照，不混合所有状态做一身彩虹衣料。
- 把“材质身份”和“当前光照响应”分别写入计划，例如“黑色织物，大暗主体，局部细碎冷亮纹”，而非笼统要求“增加反光”。源照材料不同则不能照搬这套响应。
- 风格转译默认保留原照时间／天气与主光关系；明显改成夜景、雾景或更换主光方向须当次要求。学习这组参考不等于授权所有照片加霓虹、雨水、灯具或新建筑。
- 先检查大色块与亮度排序，再检查材质差异，最后放印刷层。相同彩光照到布、石、金属、玻璃时，不能得到同一种白斑、光晕或均匀涂色。
- 验收问四件事：建筑固定结构是否仍在；黑白及其他材料身份是否仍能辨认；显示／受光／反射／空气是否分层；气氛是否来自有因果的光与纵深，而不是一层滤镜。广告换画、姿态变化不得混入光照因果结论。
