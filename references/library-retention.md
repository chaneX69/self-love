# 分类、测量与精简保留规范

本页所有“资料”“原件”“参考”“小样”均指电影截图及其电影衍生证据，不包括用户照片或用户照片生成图。视觉参考只有电影；用户照片不得自行留存为模板、训练或微调材料，亦不得进入skill及其目录备份。具体范围见[照片隐私规则](photo-privacy.md)。清理个人照片不受下方电影原件暂缓删除条件限制；技能外用户原文件及交付成品仍不得误删。

2. **视觉证据**：本机完整版保留84张无损代表整帧，见[选择清单](../data/representatives.json)；公开小样版不含整帧，改为698张色卡原像素图集和548张纹理候选小样。代表帧索引在公开版仍保留选择理由，但不表示携带整帧。两版都不改变698帧的比较范围。
3. **本机独立证据库**：完整版的698帧原件在技能之外，复用现有逐个校验的独立证据库，不再复制一套。本地通过SHA索引读取，不进入公开版本。2026-10-01作者最新明确自用完整版，因此这些仍有依赖的原件继续保留。

## 调试完成后的材质小样

2026-10-01用户已确认当前skill效果，并要求**公开小样版、本机完整版**。此最新要求取代把本机同步删成小样版的方案。公开目录必须在上传前核验全部小样、排除全部整帧；本机698张原始电影证据仍服务完整核验，不因公开版瘦身删除。分类复核、数值测试和用户效果批准分别记录，不能合并冒充全帧语义标注完成。

用户允许把有价值的材质、光照和纹理裁成小样，公开版本按[双版本规范](crop-editions.md)执行：

- 小样直接取电影原尺寸像素，不缩放、重绘、锐化或重新调色；保存源帧号、原文件与像素SHA、`x/y/w/h`、小样文件与像素SHA、类别、材料语境、光照条件、保留理由及原有测量数据关联。
- 必须保留足以判断材质、光向、反射和叠加关系的周边上下文。仅一块颜色或纹理碎片不能替代原帧的构图、空间层级、人物关系或换光对照；这些有独立价值时继续保留整帧。
- 同一小样可跨视角、场景、时段、材质、明暗索引复用，不重复存图。已接受的局部候选只作为裁样候选，不自动证明该帧其他区域无价值；歧义掩膜不冒充合格小样。
- 正式删除前先核验小样逐像素一致、全库色卡和纹理数据完整、引用有效、照片匹配和生成流程回归无退化；列出具体帧号与替代小样。缺原像素的小样外区域不得继续标作可核验，也不能在加载器中假装小样是整帧。
- 小样像素与数据完整性全部核验后才能发布；上下文是否足以批准某次照片的材料匹配，仍须当次判断。不因本次发布清空本机完整版。上线采用未打包目录，不附ZIP。

## 分别归档

- [视角](../data/archive/README.md)：平视附近、高角度、仰视、俯顶、倾斜／翻转、多分屏、非物理图形。为接触表人工视觉判断，置信度中；不声称测得镜头焦距、机位高度或精确角度。
- 场景：城市、街道、室内、人物、交通、工业、教室、细节、反射、自然环境、图形等。景别另列，不能把特写当场景类型。
- 时段：日光但时间不明、低角度日光但晨昏不明、夜晚外观、暮色外观、室内时间未知、事件时间未知、非物理图形。绝不凭蓝色判断夜晚，或凭暖色编造黄昏和钟点。
- 材质：一帧多标签，但只是可见候选，不是各材料面积分割；铜色不自动等于铜，亮边不自动等于金属或发光。
- 明暗：已测L*中位数按[0,20)、[20,40)、[40,60)、[60,80)、[80,100]分组。原图曝光未知，明暗组不等于相机曝光参数；完整分布继续保留。

各维度索引只引用同一个逐帧档案，不建立五套重复图片目录。

## 纹理比例的定义

可执行方法：[texture_features.py](../scripts/texture_features.py)；固定参数：[texture-method.json](../data/texture-method.json)；所有逐块记录：[texture-features.jsonl](../data/texture-features.jsonl)。

以色彩管理后的原分辨率sRGB，在既有ROI与排除区内按128×128原像素分块，不重采样。每块记录有效面积、局部编码亮度标准差、梯度结构张量方向一致性、Hann窗频谱前8峰能量比例、主要频率与梯度方向。边缘小块作反射填充以测特征，但分母只计真实有效原像素；过小或有效率不足90%的块不测，单独记录未测面积。

按固定顺序分类：低对比、方向结构、周期结构、混合细节。输出各类**块足迹面积**占已测面积的比例，以及阈值0.8/1.0/1.2倍下的敏感范围。范围不是置信区间；模型没有学习到材料语义，也没有经电影网点真值数据集校准。

这些特征不能自动区分：排线与发丝、丝网与衣料、波点与窗格、错版与真实彩光。真实波点／排线／细丝网／局部分色的语义像素覆盖率全部保持 `null`，不是0%。粗纹或细纹的定性观察保留在每帧学习档案，使用时仍须看实际原图。不得将频谱主频等同影片材质参数或网点频率，也不得仅凭文本反推完全相同的图像。

## 代表帧怎么选

先人工指定能解释镜面、布料、雪、纸、玻璃、皮肤、头发、光晕、故障门禁、图形插帧、跨照明对照等的核心帧，再以确定性贪心覆盖补齐已出现的类别、世界、门禁、场景×光照、材质候选×光照。当前235个检查项都有至少一张代表帧覆盖；详细保留理由与全部编号在选择清单中。

这不证明所有五维组合都覆盖，更不证明84张与698张具有完全相同的审美信息。逐色排序仍覆盖全部698帧和22,336色。完整版按需读取外部原件，公开版按原坐标读取已验证的小样；上下文不足则不批准。不能跳过更近候选来迁就已携带的图片。

## 外部证据定位

默认索引 `~/.config/self-love/archive-index.json`，或环境变量 `SELF_LOVE_ARCHIVE_INDEX` 指向另一个本地JSON。索引形如：

```json
{"original-file-sha256":"/absolute/local/evidence.png"}
```

机器路径只存在本机配置，不写入公共skill数据。`evidence://sha256/...` 是证据标识，不是网络URL。`reference_sources.py` 校验整帧文件、尺寸和像素哈希；公开版由 `palette_evidence.py` 与 `film_crops.py` 校验原像素小样。没有整帧时只能核验小样保存的范围；缺少相应小样或上下文不足则停止该项批准，不能自动通过或缩小颜色比较范围。

## 删除与回滚门槛

- 可删除skill内的已校验重复原件；先核实独立目的文件真实存在且SHA一致，再落盘删除清单。修改前留不含重复大图的规则／数据快照与原件映射。
- 代表帧必须逐像素无损。原PNG字节与WebP字节不同，比较的是ICC转换后的RGB尺寸与全部像素；原字节哈希仍保留。
- 数据必须逐字段等价；全库颜色排序、资格、无匹配、缺证据阻断、近色排除解释和明暗次序全部回归。直方图由已存数组按需绘制，省去重复图表PNG。
- 唯一证据删除需要另行确认明确范围与不可恢复影响；本机完整版仍依赖原件，真实全帧语义统计也未完成，因此本次只清理可再生派生文件和已核验冗余副本。作者已确认skill效果，不把这项批准误写成未批准，也不将其外推为全部数值标注已完成。
- 回滚仅针对本轮失败修改；规则快照与外部原件重建到隔离目录，验证后再决定恢复，不能覆盖用户并行工作。

## 编码依据

WebP无损选项与ICC携带方式见[Pillow官方文档](https://pillow.readthedocs.io/en/stable/handbook/image-file-formats.html#webp)。无损模式下quality参数控制压缩努力，不降低图像质量。本库仍用真实解码后的全部像素验证，而非只相信编码参数。

本轮“学习”是数据测量、观察归档与规则更新，不是训练或微调模型。技术通过、视觉证据核验和用户审美验收分别记录。
