# 按照片内容匹配电影剧照

2026-09-30用户要求的默认流程：以后照片转绘不能只调用抽象风格名，须对比已收录剧照，匹配人脸、配色、材质处理与小动效。这里的“动效”是静图中的动作符号，不表示生成视频。学习文件不是模型训练结果。

## 从原照到参考组合

1. **先看原照事实**：人数与身份锚点、头向／表情／遮挡、室内外与光向、冷暖比例、主材料与反光载体、静止／移动／接触／旋转证据。情绪判断只作可修正的构图理解，不推断真实心理或未知事件。
2. **全库测色，再看候选原帧**：按[强制替色流程](full-library-workflow.md)测量源照材料ROI，用 `match_photo_palette.py` 比较全库每帧全部实测色。过滤资格、材料、照明与明度角色，再按距离顺序核查实际像素落点。文件名、剧情记忆、缩略图或同帧存在该材料都不能替代像素核验。保存源色→电影色、编号/坐标/色差/更近颜色拒绝原因的替色表；待核验候选不等于匹配完成。全量计算不等于整库图片注入；无证据明确无匹配，不硬套。
3. **一套主光色，多种专用参考**：主配色选光线、明暗分区和环境条件最接近的一组；人脸另选相近视角／表情与可借鉴的体块处理，材质另选同表面响应，动作另选同动作类型。辅助帧只借指定语言，不引入其光源、发色、服饰或物件。不能把所有帧的强调色混入同一张图。
4. **动作先分类再定强弱**：依据[动作规则](action-impact-redraw.md)，轻接触与强碰撞不是一个爆点放大缩小；位移长线、旋转弧线、接触短线各有方向及落点。动作证据不足时保持安静，允许本图“动效：无”。参考中的破洞、枝条、软管、光源映像不是图形动作线。
5. **文字先建议后确认**：合适时给一句内心文案和明确视角，按[字幕规则](yellow-thought-captions.md)待确认才入图。没有答复不等于同意；只推进无文字方案，不猜文案。多人图不得擅自给所有人分配心理台词。

以上编号索引见[331–387](film-sequence-331-387.md)及[场景总索引](film-scene-cards/README.md)。这是候选路由，不是预设每张照片必用这些帧。

同场景对照优先用[388–404专项](same-scene-lighting-388-404.md)的固定表面比较法，不把不同广告、取景或姿势造成的差异归入光照。学习换光不是改写原照时间／天气的授权；主参考匹配现有条件，明确要求换光时才另定目标状态。

## 生成前留下短匹配记录

```text
原照事实：人物／光线／材料／动作证据。
主光色参考：编号；相似条件；采用的色彩角色；保留原照哪些光源关系。
全库替色表：源照与catalog哈希；全部帧/色比较数量；源ROI/HEX/Lab/xy → 目标帧/色块ID/HEX/Lab/xy/ΔE00；像素材料与光照核验；更近不合格颜色及原因；明暗顺序与主光色一致性。
面部参考：编号；体块／眉眼／鼻唇／发束；本人身份锚点；排除的角色特征。
材料参考：编号；具体表面、光泽和反光边界。
景深与边缘参考：编号；焦点及过渡／远景；舍弃的远楼与人群细节；彩边落点、相对宽窄／对比；光斑类别及光照依据。
动作：无或类型；原照证据；方向／接触点；弱、中、强的图形表现及留净区。
内心字幕：不适合／已建议待确认／文案、语言、视角已确认。
禁止导入：本次参考中的人物、道具、特殊能力、破损、背景结构。
```

光斑／彩边与用户明确认可的远景模糊效果见[405–438专项](light-and-edge-design-405-438.md)。允许远处建筑、人群主动失焦以保持干净；不将保留内容误解为每个对象同等清晰。

强弱仅为视觉设计等级，不是从单张照片测出的物理力、速度、帧率或影片固定参数。生成后把结果与原照及所选帧再次对比：身份、整体造型、主光色、各材料响应、主次清晰度、动作力度分别验收，不能只查四种印刷纹理齐全。
