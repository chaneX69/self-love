# 归类、范围与检索

先确定场景属于迈尔斯本土或彼得B原生世界，再归类。2026-09-30用户明确允许这两个世界合并学习：世界标签用于来源追溯，日常材质、光影与印刷语法联合检索，不隔成互斥风格。角色出现在画面里不充分，不凭色彩猜世界；来源不明标待核实，其余世界不自动纳入。

| 主类 | 证据要求 | 常见误判 |
| --- | --- | --- |
| 白天／常规室内 | 日光或常规室内照明、固有色与材质 | 低饱和不是没风格，荧光灯不等于荧光颜料 |
| 夜晚／低照度室内 | 暗环境、局部灯／窗／屏幕照明关系 | 蓝色不是夜晚的唯一依据 |
| 动作／冲击 | 姿态、方向、接触、受力或显著动势 | 鲜艳色块不自动代表冲击 |
| 蜘蛛感应 | 明确头周感知线或对应的空间感知图形 | 手部动作短线不是头周感应 |
| 故障 | 局部分片错接、异常重组、结构残迹 | 普通错版、能量束和网点不等于故障 |
| 稳定基准 | 无主导强特效，结构和材料清楚 | 不能把所有帧都归入故障 |

每帧记录主类、辅类、可见依据、可迁移规律、不迁移内容；没有多帧视频不声称测得运动／闪烁周期。新色卡单独测量，sRGB代表值和相对面积分开记录。

现行标签与数值以[全库清单](../data/film-library.json)为准：698帧，682活跃=474常规+208条件，16归档；全有场景级复看、材料/照明标签、32色卡、直方图、颜色明暗交叉和3×3分布。条件也包括反射与二次图像，需要兼容载体，不表示反射是禁用特效。帧标签不是像素分割，材料候选在实际采用前还需核对。下列批次计数为历史分类状态，不覆盖现行更细的条件标签。
