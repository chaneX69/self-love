# 全库实测色卡入口

唯一当前机器清单：[film-library.json](../../data/film-library.json)。当前698帧，每帧32个原像素代表色，总22,336色；每色有HEX、Lab、实际坐标、颜色簇占比与稳定ID。682帧活跃，其中474常规、208条件；16仅归档。全部测量，按资格使用。

[逐帧报告](../library.html)包含每帧观察、标签、色卡、RGB/L*直方图、颜色明暗交叉及位置分布；[方法](../color-value-relationships.md)；[全库替色执行](../full-library-workflow.md)。

旧14–55代表色色卡、42张预览与构建器已从活跃技能删除，不再作为实测结果或生成入口。旧颜色不能追溯原像素，不与新值混称。历史定性观察由[归类索引](../film-reference-taxonomy.md)检索；每帧另有统一复看记录，不限早期批次。

选色先程序比较全库，再按场景、材料、光照、色阶筛选，打开候选原帧确认实际落点。不能只读几张惯用色卡，也不将698张图片全部注入提示。本地HTML直接打开，无需服务器。

原件是用户电影截图而非官方母版；面积是采样颜色簇占比，不是物体面积。电影中的人物、服装、标志、字、UI、黑边、特殊能力和新物品不能随色卡进入源照。
