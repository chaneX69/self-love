## 色卡上下文

每帧32个色卡各留128×128原尺寸RGB上下文，原图边缘内移裁切框以完整保留色卡xy。按色卡顺序4列×8行排为512×1024图集，各格的相邻位置**不代表原场景的空间相邻**。不缩放、调色、锐化或生成重绘；WebP使用无损编码，并复核解码后全部像素。

`data/palette-crops.json`逐帧保存来源文件／像素SHA、原尺寸、图集文件／像素SHA、每格原 `rect=[x,y,w,h]`、图集 `tile=[x,y,w,h]`、色卡ID与原像素块SHA。原帧标签、光照和可见材质由scene编号关联现有全量档案，标签不是像素材质分割。

`palette_evidence.py`将原坐标映射到图集坐标，逐文件、逐格、逐锚点核对后才能批准。实际照片匹配还必须看小样：只有能够明确判断材料、受光、反射和明度角色，才在审核声明中写 `crop_context_sufficient: true`；不得机械填true。上下文不足时不批准，改查更充分的合法证据；不能为迁就小样跳过更近颜色且不解释。

## 纹理上下文

`data/film-crops.json`与548条已接受局部候选一一绑定。`rect`为原分析区域，`storage_rect`包含滤波上下文，边缘至少保留 `ceil(4*sigma)+1` 个原像素，遇原图边界则截到原边界。分别保存分析区与存储区像素SHA，禁止把新增边缘算进原候选分子或分母。

公开版重算时将坐标转为小样局部坐标，保留原ROI和排除区，逐个重算阈值状态并与原RLE逐像素比较。波点、排线、细丝网与双彩错版的**类别观察、局部候选核心数、阈值带、未描区域**各自保留；它们不是全帧真实语义占比。小样验证不把旧候选升级为人工真值。

## 全量验证

```bash
python -B scripts/verify_crop_evidence.py --report /absolute/private-work/crop-check.json
python -B scripts/verify_texture_archive.py --check-sources --report /absolute/private-work/texture-check.json
python -B scripts/verify_reference_privacy.py --report /absolute/private-work/privacy-check.json
python -B -m unittest discover -s scripts -p 'test_*.py'
```

第一项必须检查全部698张图集、22,336个上下文块／色卡锚点与548个纹理小样，不抽样替代。第二项检查698帧档案并重算548个接受候选。公开版独立验收时把 `SELF_LOVE_ARCHIVE_INDEX` 指向技能外空JSON `{}`，证明不借作者原件过关。

构建者还必须在原件仍可读取时执行 `verify_crop_evidence.py --compare-originals`，将每个保留小样的全部像素与整帧对照；重新计算全部698帧的直方图与色卡，记录测量字段摘要。`measurements_sha256`不包含两版不同的视觉资产路径，但包含逐帧其他字段，必须一致。小样只能重新核验已保存范围；公开版的整帧直方图是原件阶段已验证的存档，不从小样重复估算整帧直方图。

数值检验不等于每个小样重新做过人工语义标注，也不等于所有实际照片的转绘效果与整帧完全相同。差异与不足必须记录，不能写“零审美信息损失”或“全平台已验证”。验证失败则修复对应构建，并只回滚本次失败修改；禁止删除原件掩盖错误。
