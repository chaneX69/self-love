# 提示结构与验收

先分析源图，按[全库流程](full-library-workflow.md)完成所有帧色卡比较、候选像素材质核验和替色表，再按[照片匹配](photo-reference-matching.md)查看脸、材料、光照及动作参考。缺少实际测量或只返回待核验候选，不得进入生成。不得把示例当固定色板。

含当次照片特征的提示、替色表、测量和验收记录仅用于当次私有工作，不写入skill或公开备份。用户原照及生成图永不自动成为参考模板或训练材料；视觉参考只来自电影截图与电影小样，见[隐私条款](photo-privacy.md)。

## 提示骨架

编辑目标是原照；电影截图仅为绘制语言参考。从迈尔斯本土与彼得B原生世界联合库选择场景匹配参考，完整重绘人物与环境，不保留可见摄影底层，不拼贴不相容光线。

保持：[比例、人数与遮挡、主要脸型／头向／表情、姿态、服饰、建筑轮廓、门窗、物件、透视、原有光向]。

造型：[哪些体块先概括，哪些表情／接触／建筑结构线保留，哪里减少细节]。

轮廓线条（城市／建筑图必填）：[近处关键建筑哪几段用粗／细／有色墨线建立体块]；[哪些受光边由相邻色面相接而停笔]；[哪些阴面檐口、雕饰、窗洞只画选择性短线]；[远楼哪些窗组和外缘减线、失焦]；[局部双色错版与核心线的窄幅偏移位置]。线条应随形体和景深变化，避免整图连续等粗黑勾边、每块窗玻璃全封闭描框或把印刷色散当作发光描边。用户所说的“轮廓线条处理”不是默认故障断带或动态线抖动。

人物轮廓线条（有人时必填，独立于面部、纹理和错版验收）：[每位主要人物的头发／肩背／手臂／衣服／腿与遮挡处，哪些边段是粗墨、细墨或无墨色面]；[阴影交界线在哪里加重、哪里渐细并停笔]；[两色错版只落在哪些局部，如何与真实墨线区分]；[所选电影帧中可见的人物笔线证据]。必须让线宽跳变和局部停笔在整图尺寸可见。连续同宽的人物轮廓、整圈彩色描边、后加噪点或排线都不能替代动画体块与笔线设计。

景深（每图必填）：[焦点人物／建筑／物件]；[近旁过渡层保留哪些空间锚点]；[远景楼体／人群合并为哪些软轮廓和低细节色团]；[哪些窗格、砖缝、人脸与衣物细节不再清晰]。保留总体分布和遮挡，不增楼、不清空人群；柔化、减对比与色版失焦按层配合，纹理和彩边也同步退后。建筑作为主体时仍可清楚，不机械按距离全糊。见[光与景深专项](light-and-edge-design-405-438.md)。

面部（有人时必填）：[每个人可见的身份辨识锚点] → [电影动画式颅面／眉眼／鼻唇／下颌设计]，允许适度调整五官形状与比例，保持本人、头向、目光和表情；[简洁体面、选择性线条、哑光皮肤与发束]。不保留照片脸加纹理，不直接换成迈尔斯／彼得，不统一大眼。详见[面部设计](face-design.md)。

材料：[对象A的表面结构／光泽／高光形状／反射来源]；[B]；[C]。没有证据的材料或反射不新增。
反光（有才填写）：[载体边界、映像对象、透射或屏内内容、前方遮挡、高光方向]；本人映像与实体统一动画化，不增加人数。故障（满足条件才填写）：[发生层、局部范围、块片方向与尺度、稳定对照]；屏内异常不扩散到现场或反射层。

配色：[源照光照条件] → [已核验替色表：源ROI/HEX/Lab → 目标帧/色块ID/HEX/Lab/xy/ΔE00]，分别约束大环境、深暗、材料中间色、小焦点、高光及柔和过渡。核验指选中色块实际落点，不冒充整图语义分割；全库比较不能省略，不将整图硬量化，不固定水彩、荧光或青紫。

明度预检（每图必填）：[源图与预期成品的整图L*第25／50／75分位及明暗排序]；[面积大的天空／墙面等ROI占比、源与目标L*范围]；[要压暗或提亮的具体表面和仍须保留的亮部]。用户说“稍暗”等相对词时先对当前图确定可回看的范围。范围依据源图及已核验电影像素，不把别的照片数值设为通用标准；HEX是参照，不是生成器的精确控制指令。见[配色与明度纠错](workflow-failure-modes.md)。

动作匹配（每图判断）：[无／轻触／拍击／明显撞击／位移／旋转] → [原照证据与参考编号] → [具体落点、方向、强弱、作用范围与留净区]。不把轻接触画成强爆点，不把枝条、软管、反射灯环或玻璃破口当抽象动作线。

内心字幕：[不适合／已建议一句并待确认／已确认的逐字文案、语言与人物视角]。适合时可主动建议，未确认不得将建议写进生成画面；未确认时明确无新文字。

纹理：少量大圆点放[原有色面]；中尺度排线放[转折／阴影]并按[方向]组织；低对比细网目放[次要大面]。留净[眼口手及重要结构]。

错版：来自本图的[两色]；[主体身体衣物的局部落点、方向、较窄宽度]；[背景建筑边缘的选择性分色、相对更软／更宽但较低对比]。核心几何稳定，主体五官不分裂；不把背景失焦边缘强行描回锐利黑线。

光斑（有光照依据才填写）：[表面受光／透明多边形眩光／轮廓光／灯源光晕]；[光源关系、形状、相对尺寸与透明度变化、网点过渡、留净区]。真实地面亮区服从平面和遮挡，鬼影不当实体物件；光效不取代景深或双彩错版。

其他附加模式：[只有满足各自触发时填写，否则明确不添加感应线／故障／分镜]。动作按内容主动匹配，字幕须确认，二者不取消蜘蛛感应的明确口令门槛。

不导入参考角色、衣服、物体、字、UI或黑边；不统一动漫脸，不塑料全身白斑，不撕纸贴纸，不全局RGB平移，不添加场景。

## 验收顺序与停止条件

先读[统一验收记录](acceptance-record.md)：目标在生成前固定，门槛分项记录并绑定成品版本，缺测不通过；人物、建筑、反射的适用性须有原照依据。下文负责实际看什么，记录检查器不负责判断画风。

先通过两个互不替代的门槛：A，整体造型、材质光照、空间层次、配色关系符合所选联合参考；B，波点、排线、丝网纹理、双彩色散四项全有。A错不能加重B补救；B缺不能以A通过交付。没有通过时只能明确报告失败，不能包装成成功测试。

1. 文件：真实生成路径、尺寸、格式、原始比例误差；不把工具成功当画面通过。
2. 内容：主要人物及局部被遮挡的主体人数核对，镜像单独核对；比较头向、手的关系、相对位置、建筑体量、原有物品。远处人群按原有分布／疏密／色团检查，允许个人五官、衣物和密集小轮廓不可读；远楼窗格细节可消失，不要求为逐项点数而锐化。不能清空人群或新造楼体。小字近似必须披露。
3. 完整重绘：忽略纹理与彩边之后，轮廓、体积、明暗和材质是否已成为绘制动画？有人物时单查面部是否同时做到电影动画式重构与本人可辨认。若仍是照片脸／照片底图，或统一动漫脸／电影角色换脸，失败。
   人物线条专项：分别在整图尺寸与人物局部放大观看每位主要人物。头发、肩背、肢体、衣褶与遮挡边是否有清楚的粗细跳变、停笔和由色面代替黑线的段落？局部双色错版是否独立于墨线？若只看到平滑连续同宽的外轮廓，或靠加网点、排线、彩色外圈伪装，直接判造型失败；不能用整体色调或纹理合格抵消。
   建筑线条专项：近处山花／檐口／雕饰的线宽、深浅与停笔是否随受光面和体积变化？窗框实体结构与外加绘制轮廓是否可区分？远楼是否减线而非逐格描黑？线条停笔不能擦掉楼角、檐口和遮挡锚点。全图统一黑色细描边即使文件和构图正确，也不通过当次迈尔斯本土线条目标。
4. 材料：肤色与衣物、金属与墙面、透射玻璃与不透明面是否有不同响应？高光／反射是否有原照依据？不能全部磨砂或全部塑料亮。
   反光专项：镜内外身份、姿态与服饰是否对应？显示／透射、表面映像与高光是否分层？可辨映像是否仍可读而非一律模糊？故障是否误把映像、相机旋转或窄错版当结构碎裂，是否越过原有表面边界？见[反射专项](reflection-design.md)。
5. 光影：主要光向／投影／接触暗部成立，无凭空夜景、雨地、屏幕光。配色有主次，没有全场强制荧光。
   替色专项：按输出同物体/同角色ROI，对比目标HEX/Lab、L*分位、面积与位置关系，并核对生成前写下的整图分位与大面积ROI范围；记录偏差，不承诺生成器逐像素精确。不能用全图平均色差、提示词中的HEX或局部近色宣布电影质感通过。
   同场景换光专项：材料身份是否保留，而响应按表面分别设计？建筑暗下或远景雾化是否只改变可见度而未重排轮廓／窗组？屏幕自发光、物体受光、表面反射、空气遮蔽是否分层？详见[388–404](same-scene-lighting-388-404.md)，不以统一滤镜或一圈亮边代替这些关系。
6. 三层纹理：缩放观看可区分大点／排线／整体细印刷感，100%确认细网目并非压缩噪点；不要求微细网目在缩小尺寸仍逐根可数。
7. 主体与背景分层：主要人物身体的局部双彩错版可辨，非只有头发；关键五官／手指不分裂。远处栏杆、屋顶、窗缘可色偏失焦，宽窄与对比依焦平面变化，不误画新几何。适屏先看到主体、远景安静；100%查遮挡与柔化边界，不能出现抠图白边、模糊侵入脸或背景锐利纹理抢焦。全景等锐、全景等糊、背景高彩噪声、统一霓虹圈都不通过。
8. 无污染：当次口令成立时，单人也加一组头周分段短线；多人按人数或用户当次指定的形式分配独立线组。没有未获准世界笔法、参考人物或内容、未触发感应线、默认分镜、新文字或电影标志。
9. 匹配：所选剧照是否分别支持人脸、主光色、材料与动作的实际处理？轻触、拍击、强撞击是否有不同尺度及符号机制？字幕是否已确认逐字文案与视角？不是每图都需要动作线或字幕；普通站姿没有图形动效可以通过。

有天气／特殊表面时加查：空中雪片、表面积雪、半调网点是否分开？结构线是否服从透视而非被排线取代？投影、刻字、磨损是否独立？物理破损是否误写为故障？源照无雪、撞击或文字时不得从196–223参考中移入。图形插帧不能反过来规定全场日常材质。

整体重绘或结构失败，停止正式流程；获用户明确追加测试授权后才回到源图。仅小偏差且结构通过，可用同任务的已验证绘画输入作唯一一次定点修正，但它仍是编辑目标，不是长期风格参考。修正后重查所有受影响项，尤其纹理和墨线引起的颜色／明度变化；未重查不能沿用前版通过。最终分开报告技术验证、视觉观察、严格参考核验和用户反馈；所有用户照片及生成图均不得自动收藏为参考、模板或训练样本，用户认可也不例外。

若用户否定画风或配色，撤销此前的相关通过判断。不要将“用户尚未认可”代替“用户已经否定”。逐项指出当前输出与匹配电影帧的区别；不要仅凭文件验证、提示词含有风格名或纹理种类齐全宣布符合。详见[通用失败模式](workflow-failure-modes.md)。
