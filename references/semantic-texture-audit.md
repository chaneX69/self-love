## 归类方法与纠错经验

1. 波点需要能辨认的重复圆形／椭圆形调子单元。窗格、灯孔、标志圆圈、食物斑点、毛孔和雀斑不是自动的波点；模糊后无法区分方格与圆点时保留不确定。
2. 排线是帮助形体或阴影读取的选定线组，不等于所有斜线。头发、胡茬、衣料织纹、砖缝、电线、眼袋弧线、指节皱褶和物件外轮廓分别判断。
3. 细丝网通常是较连续、低对比的细周期载纹。它可以叠在皮肤、墙面或光区上，但物理网格／布料与采样伪影不能只靠频谱或方向阈值排除；分不清时不批准掩膜。
4. 错版需要同一几何的空间错开彩色副本。轮廓受光、反光、自发光、渐变、服装设计色线和整块彩色背景不能代替这个证据。色度阈值常会填入彩色物体本身，必须看叠图。
5. 必须同时看场景总览和原尺寸局部：例如248眼下弧线、308近胡须面颊短痕已撤出可用排线；310脸颊圆点提案改为细格筛网且掩膜仍有歧义。601–620中的物理灯阵、服装网纹、玻璃破碎与彩光也不充当印刷层。
6. “能看见类别”与“当前算法能描出可用像素”是两次判断。一帧可以确认存在错版，却没有通过提取检查的错版掩膜；接受候选数为零不意味着语义不存在。

以上学习是可检索数据与执行规则更新，不是训练或微调模型。

## 像素口径

先由看图判断限定局部，再用亮度高斯残差或限域色度阈值提出痕迹，最后实际检查叠图。阈值算法不能独自批准语义。

RLE状态：0=未描出，不是确认不存在；1=较高阈值候选核心；2=两阈值之间的过渡带，不是统计置信区间。大圆点的残差有时只描出边环，不能把环的精确像素数当作整个实心圆点面积。矩形也不是墨迹掩膜。

分母是库中既有的保守 `analysis_region` 扣除 `analysis_exclusions` 后的原尺寸有效像素，不是已精确圈定的全部电影内容。每类分别保存候选区域覆盖率、区域内核心比例、区域内核心加过渡带比例；不同类可以重叠，不要求相加100%。同类交叠矩形按并集计数，不能重复累计。未覆盖与未描出面积均显式保留。

完整真值仍缺每帧全部电影内容边界、全幅逐像素语义掩膜及误检／漏检评估。只有这些完成后才能填全帧比例；在此之前，所有 `full_frame_semantic_share` 保持 `null`，完成标志保持 `false`。

## 后续转绘如何使用

先按原照场景、材质、光照、反射、明暗与视角选参考，再查看对应类别判据及原像素。全库698帧的实测颜色比较仍按[替色流程](full-library-workflow.md)执行，不能因纹理筛选而只查84张。

为当前照片分别决定纹理落点、频段、方向、对比、叠加关系和留净区；本次任何局部比例都不能变成所有照片固定的纹理覆盖率。用户要求四类同时成立是照片输出偏好，不代表电影每一帧都有四类。用户照片及其生成图无论是否获认可，均不收入参考库或训练资料；只保留电影证据及其统计。

## 复算与保留

在技能根目录运行：

```text
python scripts/verify_texture_archive.py
python scripts/verify_texture_archive.py --check-sources
python scripts/trace_review_batch.py --reviews data/semantic-texture-reviews.jsonl --scene 658 --out /absolute/work/texture-658
python -m unittest discover -s scripts -p "test_*.py"
```

默认核验档案一致性；`--check-sources`优先打开合法整帧，缺整帧时只使用已逐像素验证并带足滤波上下文的纹理小样，重算548个接受候选。报告分别计数整帧读取与小样重算，不能将后者称为整帧语义验证。缺小样或滤波边缘不足必须失败。公开版另须用空原件索引运行全部[小样检查](crop-editions.md)，禁止借作者目录过关。单元测试不证明语义正确。

作者本机继续保留完整版和独立原件；公开小样版排除整帧，完整保留源图身份、区域坐标、RLE、比例、原因和学习记录。分类完成不允许删除唯一原件，也不证明全帧真实语义占比已完成。当前发布已获作者另行授权，工程验收见[发布边界](release-readiness.md)。
