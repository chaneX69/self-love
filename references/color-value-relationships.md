# 色阶、颜色与空间关系

## 当前数据

[698帧全库报告](library.html) · [方法](library-retention.md) · [CSV](../data/frame-index.csv) · [JSON](../data/film-library.json)。旧593/637/698色阶段性报告仅保留项目历史，不再是当前入口。本轮统一重算，并补齐全库标签、原像素色卡及实绘直方图。

每帧：RGB各256箱、CIELAB L*100箱；L* P1/P5/P25/P50/P75/P95/P99；五段0–20/20–40/40–60/60–80/80–100；32个真实代表像素及面积；Lab色相12组加低彩中性组与五明度段交叉；原画面3×3位置统计。色相为 atan2(b*,a*) 的30°等宽箱，C*<8单列中性；这些是分析标尺，不是电影规则。

直方图横轴为编码RGB或L*，纵轴为有效采样数；面板独立缩放，须读峰值，不能只凭柱高比较通道。色阶不是相机线性曝光，五段不表示电影只画五阶。

## 四类证据

- 数值只对当前编码、采样和排除区成立，颜色面积不等于皮肤、墙、布或灯的面积。
- 观察需要看图：受光与自发光、映像与屏内显示、窗框与排线不能由直方图区分。
- 冷暖、对比、景深组织是可修正解释，不反推未知电影参数。
- 应用在原照内容、材料和光照逻辑内替换同角色颜色，同时完整重绘，不是全局LUT或全库平均色板。

## 读取顺序

1. 看大明暗形、绝对分箱与P5/P50/P95，识别深暗锚点、中间调和高亮各由什么承载。
2. 比同明度不同色、同色不同明度。青窗灯与深青楼体不可互换职责，暖色也能很暗。
3. 比颜色簇占比、位置和3×3分布，再看原图边界属于光影、遮挡、反射或错版。全局主色不能代替小面积关键材料。
4. 大点、中排线、细网分别看载体、尺度、方向、对比和留净；砖缝、衣纹、发束、雨雪不算印刷层。步长4采样可能混叠，不用于推算细纹频率，微观判断须另开原帧。
5. 同照明同材料镜头交叉核查，不把连续夜景数量多当全片偏好。同场景换光仍有姿态、云形、广告、机位变化，不是严格曝光实验。
6. 按[全库流程](full-library-workflow.md)比较源照与每帧色卡，核实像素后建替色表，暗中亮不倒序；全图色差不证明动画质感。

城市另读[建筑专项](city-color-architecture.md)。保留中性室内、暖林冷雪、夜街、餐厅和人脸各自逻辑，不强制水彩、蓝紫、荧光或灰调。
