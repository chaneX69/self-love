# 电影参考库数据

- `film-library.json`：唯一运行数据入口。698帧的来源、原件SHA-256、场景级标签、逐帧观察、色卡、直方图、色阶和空间分布均在这里。每帧32色只是代表性取样，不是逐像素语义分割。
- `film-reviews.tsv`：人工复看的可重建标签底稿，竖线分隔。260组细化观察展开成698帧；新批次必须补齐编号再重建，不用旧计数宣称覆盖新增截图。
- `view-review.tsv`：698帧人工视角／景别底稿；[五维交叉档案](archive/README.md)及 `frame-index.csv` 供分别检索。
- `frames/001.md` 至 `frames/698.md`：每帧完整色卡、比例、观察、明暗、纹理特征占比与未知边界。代表帧有图，其他帧仍有完整文字记录。
- `texture-method.json` 与 `texture-features.jsonl`：原分辨率分块图像特征及阈值敏感范围。四种印刷层的语义占比未测，字段为null，不能当成0或准确分割。
- `representatives.json`：84张代表帧与235项覆盖证据。图片使用全分辨率无损编码；非代表帧的已校验原件在本机技能外按需读取，不进入默认分发。
- 16帧仅归档，208帧须满足明确条件，474帧常规可检索；仅归档帧即使颜色接近也不可采用。条件标签不授权新增原照不存在的内容。

执行入口：[全库核对与照片替色流程](../references/full-library-workflow.md)。查看报告、原帧和采样像素后才确认材料匹配；不能仅因帧中存在某材料就给整帧色块赋予该材料。

重建时用当前 `film-library.json` 作 `--inventory`、`film-reviews.tsv` 作 `--reviews`，可保留已有原件清单和定性证据。先生成到新的临时目录并完成独立验证，再替换运行数据；不要把待验证结果直接当成合格版本。

参考定位配置见[保留规范](../references/library-retention.md)。没有完整证据库也可以计算全部色差和绘制已保存的直方图，但未能看到目标像素时不能批准材料／纹理匹配；这不是可静默降级的步骤。
